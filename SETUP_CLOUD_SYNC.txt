CROCHET BUDDY v17 - CLOUD IMAGE STORAGE

Supabase setup:
1. Open your Crochet Buddy project in Supabase.
2. Go to SQL Editor.
3. Run the entire contents of supabase_schema.sql once.
4. This keeps the existing user_data table and adds the crochet-images Storage bucket.
5. Do not use a service-role/secret key in the app.

v17 image behavior:
- Pattern cover photos, round screenshots, and Learn photos are uploaded to Supabase Storage.
- The database stores small image URLs instead of huge Base64 images.
- Existing v16 Base64 images are automatically moved to Storage after login.
- Images are resized before upload to reduce phone data/storage use.
- The same GitHub Pages URL continues to host the app.
